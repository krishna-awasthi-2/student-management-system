Welcome

This website is a basic front-end model for a Student Management System.

Project Overview

The website demonstrates how student information, course details and contact information can be arranged using HTML pages.

Project Objectives

  • To create a simple multi-page website using HTML.
  • To learn headings, paragraphs, links, lists, tables and forms.
  • To present student and course information in an organized format.

Website Sections

  2. Student registration form
  3. Student records table
  4. Course information
  5. Contact page
